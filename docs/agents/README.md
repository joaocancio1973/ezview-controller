# Agentes Sinapse

Este diretorio define os papeis oficiais dos agentes da identidade `Sinapse`.

Agentes ativos nesta fase do projeto:

- `SinapseCore`
- `SinapseAPI`
- `SinapseFront`
- `SinapseDocs`

Cada agente possui:

- missao
- responsabilidades
- limites
- exemplos de uso
- areas naturais do projeto
