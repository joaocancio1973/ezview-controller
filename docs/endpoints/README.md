# Endpoints

Este diretorio concentra a documentacao dos endpoints oficiais da API.

Padrao sugerido:

- um arquivo por dominio
- incluir metodo, rota, permissao, payload, resposta e observacoes

Dominios iniciais documentados:

- autenticacao
- admins
- condominios
- torres
- unidades
- usuarios
- areas comuns e reservas
- moradores e convites
- veiculos
- vagas de garagem
- funcionarios
- controle de acesso
- colaboradores da unidade
- prestadores de servico
- financeiro
- ocorrencias e manutencao
- manutencoes
- mensagens

- inbox da unidade
