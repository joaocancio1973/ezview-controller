# Mapa Visual do EzView

Versao HTML para leitura visual e impressao:

- [mapa-visual-ezview.html](C:/ezview-controller/docs/mapa-visual-ezview.html)

Objetivo:

- apresentar uma visao executiva do banco relacional por modulos
- organizar o fluxo real da aplicacao por perfil
- servir como material de alinhamento para arquitetura, produto e novas implementacoes

Recomendacao de uso:

1. abrir o HTML no navegador
2. revisar os modulos e fluxos com calma
3. usar a impressao do navegador para gerar PDF quando necessario
